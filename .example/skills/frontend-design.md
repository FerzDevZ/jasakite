# Frontend Design Standards
- Typography: Fluid type scale using CSS clamp, high-contrast readable fonts.
- Layout: Responsive, asymmetric bento grids, tactile micro-interactions.
- Accessibility: WCAG AA contrast standards, keyboard navigability.
