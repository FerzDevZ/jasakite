# Diátaxis Documentation Framework Guide

## The 4 Documentation Modes

1. **Tutorials (Learning-Oriented)**:
   - Walks a newcomer through building something from scratch.
   - Example: *"Getting Started: Building your first GraphQL endpoint."*

2. **How-To Guides (Problem-Oriented)**:
   - Solves a specific real-world problem for an experienced user.
   - Example: *"How to configure Redis connection pooling in Kubernetes."*

3. **Reference (Information-Oriented)**:
   - Accurate, dry, technical description of machinery, APIs, and options.
   - Example: *"REST API v1 /users endpoint specifications."*

4. **Explanation (Understanding-Oriented)**:
   - Discusses architectural choices, trade-offs, and design philosophy.
   - Example: *"Why we chose Event Sourcing over CRUD for Financial Ledger."*
