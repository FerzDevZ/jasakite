# Ferz Skills Preset Quick-Start Guide

## 1. "Fullstack Web App" Preset
Jika Anda sedang membangun aplikasi web fullstack dari nol:
- Gunakan `modern-web-design-master` + `ui-ux-design-system-expert` untuk antarmuka visual.
- Gunakan `react-nextjs-master` atau `vue-nuxt-master` untuk frontend framework.
- Gunakan `authflow-security-architect` untuk flow login/signup aman.
- Gunakan `node-typescript-backend` atau `python-fastapi-backend` untuk backend API.
- Gunakan `erd-data-modeling-expert` untuk skema database.

## 2. "Enterprise Scalability & Data" Preset
Jika Anda sedang membangun sistem skala tinggi / microservices:
- Gunakan `system-design-architect` untuk arsitektur terdistribusi.
- Gunakan `redis-distributed-locking-caching` untuk distributed locking & cache.
- Gunakan `websocket-realtime-architect` untuk fitur real-time.
- Gunakan `database-architect-optimization` untuk tuning query SQL.

## 3. "DevOps, Cloud & SRE" Preset
Jika Anda menyiapkan infrastruktur dan deployment:
- Gunakan `docker-container-master` untuk containerization.
- Gunakan `kubernetes-helm-orchestrator` untuk deployment K8s.
- Gunakan `terraform-cloud-iac` untuk cloud IaC.
- Gunakan `github-actions-ci-cd` untuk automated pipelines.
- Gunakan `observability-prometheus-grafana` untuk monitoring & tracing.
