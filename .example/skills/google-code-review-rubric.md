# Senior Code Review Rubric (Google & Meta Standard)

## Review Priority Order

1. **Design**: Is the code well-designed and appropriate for this system?
2. **Functionality**: Does the code behave as the author intended? Are edge cases handled?
3. **Complexity**: Could the code be simpler? Will future developers misunderstand it?
4. **Tests**: Are unit, integration, and regression tests added with high quality?
5. **Naming**: Are variables, classes, and methods clear, unambiguous, and intention-revealing?
6. **Comments**: Do comments explain **WHY**, not **WHAT**?
7. **Style**: Does the code match the project style guide (should be automated by linters)?
