# Zero-Trust Architecture Core Principles

## The 3 Pillars of Zero-Trust

1. **Verify Explicitly**: Always authenticate and authorize based on all available data points (identity, location, device health, service, data classification).
2. **Use Least Privilege Access**: Limit user and service access with Just-In-Time (JIT) and Just-Enough-Access (JEA) models.
3. **Assume Breach**: Minimize blast radius by segmenting access by network, user, devices, and application awareness. Encrypt all sessions end-to-end.
