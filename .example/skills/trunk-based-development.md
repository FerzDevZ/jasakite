# Trunk-Based Development & Conventional Commits Guide

## Conventional Commit Types

| Type | Intent | SemVer Bump |
|---|---|---|
| `feat` | Introduces a new feature to the codebase | **MINOR** (`1.1.0`) |
| `fix` | Patches a bug | **PATCH** (`1.0.1`) |
| `perf` | Improves performance | **PATCH** (`1.0.1`) |
| `refactor`| Refactors code without fixing a bug or adding a feature | **PATCH** (`1.0.1`) |
| `docs` | Documentation changes only | None |
| `chore` | Build process, auxiliary tool changes | None |
| `BREAKING CHANGE:` | Contains breaking API changes | **MAJOR** (`2.0.0`) |
