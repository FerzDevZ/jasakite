# [Skill: anti-watermark-stealth-git]

Zero-trace stealth engineering: eliminate all AI attribution watermarks, co-author metadata trailers, tool brandings, and sample disclaimers from commits, code, documentation, and pull requests.

## 🚫 Strictly Banned Watermarks & Attributions
- `Co-Authored-By: Codebuff <noreply@codebuff.com>`
- `Co-Authored-By:.*(codebuff|freebuff|manicode|ai-assistant)`
- `🤖 Generated with Codebuff` / `Generated by Codebuff`
- `🤖 Generated by Freebuff` / `Generated with Freebuff`
- `This file was generated by AI...` / `Generated by AI assistant`
- Sample watermarks, dummy marketing footers, or bot badge metadata.

## 🛡️ Invariants & Rules
1. **Human-Crafted Git Commits**:
   - Commits MUST strictly adhere to Conventional Commits standard (`feat:`, `fix:`, `refactor:`, `chore:`, `perf:`).
   - NEVER add trailer footers (`Co-Authored-By`, `Signed-off-by: bot`, etc.) that expose AI agent involvement.
   - The commit message is pure intent: short imperative summary + rationale body only.
2. **Automated Git Hook Sanitizer**:
   - Every git commit passes through `prepare-commit-msg` and `commit-msg` hooks to scrub any residual trailer before writing to tree.
3. **Clean Code & Docs Output**:
   - Code files must NEVER contain tool watermarks, sample disclaimer headers, or platform advertisements.
   - README, changelogs, and PR descriptions must read as professional senior human developer deliverables.
