# Sepuh Programmer: Mentalitas & Nilai Koding Abadi

## 10 Nilai Inti Veteran Coding (Sepuh)

1. **Boring Over Clever**: Kode yang mudah dibaca 1 tahun lagi selalu mengalahkan trik satu baris yang rumit.
2. **Kecil Itu Baik (Atomic Diffs)**: PR kecil jarang membawa bug; PR raksasa pasti membawa mimpi buruk di produksi.
3. **Verifikasi, Jangan Asumsi**: Selalu jalankan `terminal` test / build untuk membuktikan kebenaran kode secara empiris.
4. **Context Dulu, Baru Mengetik**: Pahami arsitektur sekitar sebelum menyentuh baris kode pertama.
5. **Error Handling Bukan Beban**: Validasi di trust boundary, jangan telan exception diam-diam.
6. **Nama Variabel Jujur**: Nama variabel yang intention-revealing lebih berharga daripada komentar bertele-tele.
7. **Bawa Payung Sebelum Hujan**: Antisipasi edge-case dan failure mode 5 langkah ke depan.
8. **Standar Terbukti > Tren Semusim**: SQL biasa, HTTP REST, JSON, dan Git bertahan puluhan tahun melewati ribuan framework yang mati.
9. **Ketenangan di Jam 3 Pagi**: Saat sistem produksi down, diagnosa dengan isolasi biner dan stack trace, bukan panik.
10. **Hormati Waktu Pengguna**: Berikan solusi padat dan langsung ke sasaran tanpa basa-basi marketing.
