# Hallmark — Anti-AI-Slop Design System

A design skill for AI coding assistants. Makes generated UIs look crafted by master human designers, not generated by generic AI templates.

Hallmark insists on **structural variety**, **locked tokens (OKLCH)**, and **real typography hierarchy**.

---

## 🚫 6 Disciplines of Hallmark (Universal Laws)

1. **Pre-Emit Self-Critique:** Score output 1–5 on Philosophy, Hierarchy, Execution, Specificity, Restraint, Variety. Scores < 3 trigger a revision pass. Stamp: `/* Hallmark · pre-emit critique: P5 H4 E5 S4 R5 V5 */`.
2. **Honest Copy (No Fabricated Content):** Never invent fake metrics ("+47% conversion", "trusted by 50,000+ teams"). Use real metrics or label as `— (metric to confirm)`.
3. **Locked Tokens (No Mid-Render Improvisation):** All colors and fonts must reference named CSS variables (`var(--color-accent)`, `var(--font-display)`). No inline raw hex/OKLCH.
4. **Re-Drawn Chrome Forbidden:** Never hand-build fake browser bars, fake macOS dots, or fake phone frames. Wrap real UI in a clean `<figure>`.
5. **Mobile Responsiveness (Strict 320/375/414/768px):** No horizontal scroll (`overflow-x: clip`), no two-line buttons, image grid tracks use `minmax(0, 1fr)`.
6. **Typography Purity (No Italic Headers):** Headings are always upright roman (`font-style: normal`). Use weight or accent color for emphasis.

| Invocation | Action |

| `hallmark redesign <target>` | Redesign visual/interaction layer inside existing implementation boundaries. |
| `hallmark study <URL\|img>` | Extract visual DNA (type pairing, palette, rhythm) and emit `design.md`. |

## 🎨 Page Design Flow (Step-by-Step)

1. **Step 0 · Pre-flight Scan:** Read existing tokens, fonts, and frameworks.
2. **Step 1 · Signal & Genre Detection:** Identify genre (Editorial, Modern-Minimal, Atmospheric, Playful).
3. **Step 2 · Macrostructure & Theme Pick:** Pick 1 of 21 named themes (e.g. *Ember Warmth*, *Nordic Pine*, *Obsidian Luxury*, *Swiss Studio*) or construct custom OKLCH palette. Consult `references/themes.md` and `references/structure.md`.
4. **Step 3 · Layout Construction:** Apply fluid typography (`clamp()`), asymmetrical bento grids, and high-contrast WCAG AA surfaces.
5. **Step 4 · Slop-Test Verification:** Verify against `references/slop-test.md` (no purple AI gradients, no cookie-cutter 3-card rows).

---

## 🧩 Component-Scope Flow

When brief refers to a single UI element (button, card, modal, input, dropdown):
1. Inherit project's existing design tokens (`tokens.css`).
2. **Mandatory 8-State Support:** Every interactive component must handle: `default`, `hover`, `:focus-visible`, `:active`, `disabled`, `loading`, `error`, `success`. Consult `references/interaction-and-states.md`.
3. Emit component alongside `<ComponentName>.preview.html` 8-state demo wrapper.
