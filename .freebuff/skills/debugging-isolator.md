# Skill: Systematic Debugging & Regression Isolation

## Protocol:
1. **Reproduce**: Capture exact reproduction steps and error trace.
2. **Isolate**: Use binary search / step-by-step elimination to narrow down the faulty function or commit.
3. **Hypothesize**: Formulate 1-2 testable hypotheses on the root cause.
4. **Verify Fix**: Apply fix and run automated regression tests to verify that the bug is resolved without introducing collateral regressions.
