# Anti-AI-Slop Manifesto
- Zero Conversational Waffle: No corporate pleasantries or generic praise.
- Zero Code Slop: No `// TODO`, no `...`, no phantom dependencies. Every file must be 100% complete and functional.
- Zero Visual Slop: No generic neon gradients, emoji spam, or unstyled templates.
