1   Ringkasan Eksekutif

JASAKITE adalah marketplace jasa lokal nasional yang membuat "cari tukang" semudah pesan makanan. Pelanggan membuka katalog, memfilter berdasarkan kota/provinsi (mis. Kepulauan Bangka Belitung), membandingkan harga formatIDR, rating RatingStars dan ulasan asli, lalu checkout dengan alamat lengkap + deadline. Provider menerima order di Kanban drag-and-drop (PENDING → IN_PROGRESS → COMPLETED), mengerjakan, dan menandai selesai. Customer memberi rating 1-5; ratingAvg ter-update transaksional. Admin memoderasi jasa DRAFT, melihat 5 KPI + 2 grafik, dan mengekspor CSV. Semua berjalan di Next.js 15 App Router + Prisma + MongoDB Atlas, deploy Vercel Singapore (sin1) untuk latensi rendah ke Indonesia.

6.5 Fitur Sistem

  • FSM Order lib/order-status.ts:17 PENDING → IN_PROGRESS → COMPLETED (terminal) + CANCELLED dari PENDING/IN_PROGRESS (customer hanya CANCELLED). completedAt hanya saat COMPLETED (jendela ulasan 60 hari tidak reset). Guard di PATCH /api/orders/[id] 409 + UI sembunyikan tombol ilegal.
  • Rate Limit Token Bucket lib/rate-limit.ts MAX 10k + sweep periodik, per-user clientKey, header RateLimit-*, 14 rule (register 5/jam, login 10/m, order 20/jam, review 10/jam, impersonate 10/jam, export 5/5m, dll).
  • Upload Device canvas 1280 jpeg 0.82, fallback URL, unoptimized untuk data: (Next Image).
  • Seed Nasional 46 jasa 44 aktif, galleryPool per kategori (2 foto tambahan selain foto utama), addressSamples 20 kota, deadline future.
  • Dark Mode penuh — token light/dark terpisah, toggle ThemeProvider.

  ↓ klik ServiceTile "Bersih Rumah Bangka"

  ↓ POST /api/orders (address required, deadline future, self-order 400)
[Orders/[id] — OrderTimeline + estimasi createdAt+deliveryTimeDays + chat + cancel dialog]
  ↓ Provider: Dashboard Kanban drag Terima → IN_PROGRESS
[Notification bell 30s (updatedAt) → Provider Tandai Selesai → COMPLETED]
  ↓ Customer: ReviewForm 5★ Arrow keys → POST /api/reviews transaksi
[Service ratingAvg 4.48 recompute, Dashboard Total Belanja update]
FSM Guard: TRANSITIONS = { PENDING: [IN_PROGRESS, CANCELLED], IN_PROGRESS: [COMPLETED, CANCELLED], COMPLETED: [], CANCELLED: [] }. Customer hanya boleh CANCELLED; provider boleh IN_PROGRESS/COMPLETED. Violasi → 409 + toast.
