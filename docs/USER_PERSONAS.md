## 📊 User Flow Utama

### Flow 1: Customer Memesan Jasa

```
1. Buka Beranda
   ↓
2. Klik "Cari Jasa" atau gunakan Search
   ↓
3. Browse Katalog dengan Filter
   (kategori, lokasi, harga, rating)
   ↓
4. Klik Jasa → Halaman Detail
   ↓
5. Lihat Deskripsi, Rating, Provider
   ↓
6. Klik "Pesan Sekarang"
   ↓
7. Isi Form Checkout
   (alamat, jadwal, catatan, metode bayar)
   ↓
8. Konfirmasi Pesanan
   ↓
9. Lihat Status Pesanan
   ↓
10. Chat dengan Provider
    ↓
11. Pesanan Selesai → Beri Review
```

### Flow 2: Provider Menerima Pesanan

```
1. Login → Dashboard Provider
   ↓
2. Lihat Kanban Board
   (Menunggu → Dikerjakan → Selesai)
   ↓
3. Klik "Terima & Kerjakan"
   ↓
4. Chat dengan Pelanggan
   ↓
5. Kerjakan Pesanan
   ↓
6. Klik "Tandai Selesai"
   ↓
7. Terima Review dari Pelanggan
```

### Flow 3: Admin Memoderasi

```
1. Login → Dashboard Admin
   ↓
2. Lihat Ringkasan Platform
   (KPI, Grafik, Statistik)
   ↓
3. Klik "Moderasi Jasa"
   ↓
4. Review Jasa yang Masuk
   ↓
5. Setujui / Tolak
   ↓
6. Lihat Statistik Pengguna
   ↓
7. Export Data (CSV)
```

## 🎯 Key Insights

### 1. Mobile-First is Essential
- 80%+ pengguna akan akses dari HP
- Semua flow harus nyaman di mobile
- Bottom sheet untuk filter
- Floating CTA untuk aksi utama

### 2. Trust is Critical
- Rating dan review harus kredibel
- Provider harus terverifikasi
- Harga harus transparan
- Status pesanan harus jelas

### 3. Simplicity Wins
- Flow pemesanan harus simpel (3-5 langkah)
- Form harus mudah diisi
- Feedback harus jelas (loading, sukses, error)
- Navigation harus intuitif

### 4. Local Context Matters
- Format mata uang IDR
- Bahasa Indonesia
- Format alamat Indonesia
- Provinsi/kota yang benar
