KRITERIA 4: KREATIVITAS & INOVASI • BOBOT 15% Keunggulan Teknologi Orisinal
11 / 14
4 Inovasi Orisinal yang Tidak Ditemukan pada Template Biasa
Solusi rekayasa cerdas yang memecahkan kendala teknis nyata di lapangan.
1. FSM Transaction Guard (Finite State Machine)
Status pesanan tidak bisa dilompati sembarangan. Transisi dari PENDING → IN_PROGRESS → COMPLETED dikunci dengan proteksi API HTTP 409 Conflict jika terjadi benturan update ganda dari dua perangkat.
2. Client-Side Image Compression (HTML5 Canvas)
Penyedia jasa di pelosok daerah seringkali memiliki kuota internet terbatas. Saat upload foto jasa, gambar otomatis di-resize menjadi maksimal 1280px dengan kompresi kualitas 0.82 langsung di browser sebelum terkirim ke server (hemat kuota 80%).
3. City-Indexed Query Architecture
Kolom kota diekstrak dan diindeks secara khusus di basis data MongoDB/Prisma, bukan dihitung berulang-ulang saat request tiba. Pencarian ratusan jasa di suatu kota selesai dalam latensi sub-50 milidetik.
4. 3 Dashboard Spesifik Peran (Role-Tailored)
• Admin: Analitik gaya Stripe & PostHog (Volume & KPI pengerjaan).
• Provider: Papan Kanban drag-and-drop gaya Linear dengan titik status warna.
• Customer: Daftar aktivitas ringkas gaya Gojek tanpa beban informasi rumit.
